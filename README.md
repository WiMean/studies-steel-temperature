# Прогнозирование температуры плавления стали (промышленность)

**Задача.** Металлургический комбинат хочет снизить потребление электроэнергии на этапе обработки стали. Нужна модель, предсказывающая температуру стали.

**Что сделано.** Объединение данных из нескольких источников, обработка выбросов и пропусков, feature engineering, сравнение CatBoost, LightGBM, XGBoost и нейронной сети, кросс-валидация, отбор признаков.

**Стек.** Python, pandas, scikit-learn, CatBoost, LightGBM, XGBoost, Matplotlib

**Результат.** MAE лучшей модели 6,11 °C

**Ноутбуки:**

- `steel-temperature.ipynb`
